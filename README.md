# 🎞 Кадр Мяфли для SillyTavern

Картинка сцены прямо под ответом персонажа. Это перенос плагина «Кадр» из Tavo: те же стили, герои с фото и шёпот.
Автор: Вика-Мяфля (@vika_myaflay). Стили SLAY — автор Wewwa.

## Установка

Без GitHub, просто папкой:

1. Распакуй архив. Внутри папка `Kadr-Myaflya`.
2. Положи её целиком в папку расширений SillyTavern:
   - новые версии: `SillyTavern/data/default-user/extensions/`
     (если у тебя свой пользователь, то `data/<имя>/extensions/`);
   - старые версии: `SillyTavern/public/scripts/extensions/third-party/`.
3. Перезапусти SillyTavern (или обнови страницу).
4. Расширения (кубики) → блок **🎞 Кадр Мяфли**.

## Настройка

**Провайдер** — адрес (обычно заканчивается на `/v1`), ключ и модель для картинок:
- gpt-image-1 и похожие → тип «/images»;
- Gemini / Nano Banana → тип «/chat»;
- или оставь «сам угадает».

Ключ хранится только в настройках твоего SillyTavern и уходит только на адрес провайдера.

**Герои** — персонаж и твоя персона подтягиваются сами, вместе с аватарками.
- Можно добавить свои фото и описание внешности на английском, без слов «не».
- «✨ взять из карточки» — модель сама выпишет внешность из карточки.
- Второстепенных героев добавляешь по имени.

**Стиль** — 27 стилей Кадра (включая 😂 Мемный кадр), вся библиотека SLAY и свои стили.
- ⚡ Молния — быстро, без фото героев.
- 🚀 Быстро — с фото героев.
- 🧠 Умно — сначала модель пишет сцену, потом рисуем.

## Как рисовать

Под каждым ответом персонажа есть кнопка **Кадр**:
- рядом быстрый выбор стиля из избранного;
- «✎ шёпот» — пожелание к кадру: «крупно», «со спины», «Нора на столешнице»;
- картинки сохраняются в галерею SillyTavern (папка `Kadr`), листаются ‹ › и скачиваются ⤓.

Если пресет пишет строку `[КАДР: …]`, сцена берётся из неё. Если нет, Кадр берёт конец ответа.
